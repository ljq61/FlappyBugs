## 渲染接线与碰撞约定

- `ART` 以41个显式 `new URL(..., import.meta.url)` 条目引用原稿，兼容 Vite 静态资源解析；`OBSTACLE_ART` 返回7种障碍的 bottom/top、stem、stemColor、collisionWidth、capHeight与dangerKind；藤蔓另有flameBottom/flameTop字符串ID。
- 甲虫与后翅统一256×256坐标。绘图整体平移(-8,-15)，使身体中心接近画布中心；bodyBounds 为 `[30,55,198,143]`，建议调试 collisionBounds 为 `[43,69,170,118]`（像素，x/y/宽/高）。触角、腿、后翅与气团是装饰，不参与身体碰撞。
- 甲虫推进、下落切换flap/fall原稿并配合旋转、挤压与独立后翅频率；无敌时身体及两侧后翅通过shader显示流动彩虹，光环辅助辨识；受伤和失败切换独立表情资源。没有引入逐帧大图。
- 后翅的 pivot 为 `[131,110]` 像素。应绘制在甲虫身体后方，独立调整透明度和轻微摆动。
- 障碍端部 viewBox180×150，视觉保持在约x4..176；tip 为下障碍 `[90,5]`、上障碍 `[90,145]`。端部真实 tip 应贴合通道边缘，处理约5像素透明留边。
- 以 collisionWidth1.78 显示端部时，推荐 capHeight1.48 保持原稿比例。端部不可按整根柱长拉伸；茎干由渲染器单独绘制与伸缩。上端资源自身朝向正确，无需翻转下端五刺帽冠。
- 障碍碰撞为宽1.78的连续柱体，与危险针冠/五刺外形之间留有少量透明区域容差；可见端部不是逐像素碰撞承诺。主 agent 必须在 debug 轮廓与真实输入中复核。
- 平台资源是起飞画面装饰，不自行定义玩法碰撞。背景固定720×1280构图，逻辑视野始终9×16。
